## Reportar una vulnerabilidad

**No abras un issue público.** Usa *Private Vulnerability Reporting* en la pestaña Security de este repositorio.

Incluye:
- Descripción de la vulnerabilidad
- Pasos para reproducir
- Impacto potencial
- Versión afectada
